# Contributing to HA-NWR-SDR

Thanks for your interest in contributing! This is a community project and all contributions are welcome.

## How to contribute

- **Bug reports** — use the [bug report template](.github/ISSUE_TEMPLATE/bug_report.md)
- **Feature requests** — open an issue describing the feature and your use case
- **Pull requests** — please open an issue first for large changes so we can discuss approach

## Good first contributions

- Testing on different RTL-SDR hardware (V3, V4, generic)
- Adding Sonos / Google Home audio examples to the docs
- Android vs iOS notification optimization tips
- Documentation improvements
- Non-US / Canadian Weatheradio adaptations (different SAME codes/frequencies)

## Code style

- Python: follow PEP 8, keep comments clear
- YAML: 2-space indent, descriptive entity names
- Keep `# ← EDIT` markers on any line a user must customize
